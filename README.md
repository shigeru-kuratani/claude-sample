# サブスクリプション ダッシュボード

モバイルアプリのサブスクリプション契約状況を確認できる社内デモ用ダッシュボードです。

## 見られる指標

- 有効サブスク数
- 新規契約数
- 解約数（月次換算解約率つき）
- MRR（月次経常収益）
- トライアル転換率

## 絞り込み

- 期間（7日間 / 30日間 / 90日間 / 180日間 / 1年間 / 全期間）
- OS（すべて / iOS / Android）
- プラン（すべて / 月額 / 年額）

絞り込みに応じて、KPI・グラフ・内訳がすべて連動して再計算されます。

## データについて

すべて `index.html` 内で生成されるダミーデータです（トレンド・週次/季節性・突発的なスパイクを含む乱数生成）。実際の契約状況を反映するものではありません。

## 使い方

ビルド不要の単一HTMLファイルです。`index.html` をブラウザで直接開くだけで動作します。
